# 实验记录：成立的结果

这里只放**成立**的结果。已否证的假设、失败的分支、诊断性的上界都不进这个文件夹
——它们在 `docs/` 里的分析文档中，和否定它们的证据放在一起。

## 收录标准

一条结果要进来，必须同时满足：

1. **有数字**，而且是能追溯到某次具体 run 的数字，不是"看起来变好了"。
2. **写清边界**：哪个场景、哪段帧窗、哪一代（generation）、多少 prompt。
   没有边界的正面结果是无法被后续工作使用的——它会在下一个场景里被当成承诺。
3. **写清它相对什么**：相对 raw，还是相对上一版方法。
4. **有复现入口**：一条能跑的命令。
5. **预先声明的判据通过了**，而不是事后挑一个变体来讲故事。

## 不收录

- 只在一部分指标上变好的结果（那是一个待解释的现象，不是一个结论）
- 阈值是在被评测的那段窗口上选的，却没有说明的结果
- 事后选的变体：如果变体是看着结果挑的，写进来时必须标明
- 用 GT 参与生成的结果。GT 只用于评测；唯一例外是明确标注
  `not_a_method_result: true` 的诊断上界（如 mask oracle），它不进这个文件夹
